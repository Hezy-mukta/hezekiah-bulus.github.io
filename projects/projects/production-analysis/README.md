# Oil & Gas Production Performance Analysis

## Introduction

This project analyzes oil and gas production data
to identify production trends, geographic patterns,
and potential operational opportunities.

## Business Problem

How can production data be analyzed to identify
production trends, high-performing locations,
and potential areas of concern?

## Business Questions

1. What is the overall production trend?

2. Which locations contribute the most production?

3. Which commodities contribute most to production?

4. Which locations experience production declines?

5. What insights can support operational decisions?

## Data

The dataset contains production date,
location, commodity and production volume.

## Data Cleaning

The following steps were performed:

- Removed duplicate records
- Checked missing values
- Standardized categories
- Converted dates
- Converted volume to numeric format
- Checked data types

## Analysis

The data was analyzed using:

- Excel
- SQL
- Python
- Tableau

## Key Findings

Findings will be documented after analysis.

## Solution

A production monitoring dashboard can help
operational teams track production performance.

## Conclusion

This project demonstrates how data analytics
can transform raw production data into useful
business insights.
